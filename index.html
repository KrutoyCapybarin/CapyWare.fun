Core Features

CapyWare is a fully external executor. It reads and writes Roblox process memory, runs Luau scripts in a custom VM, and exposes a wide API surface.

Luau VM

Custom Luau interpreter with coroutine scheduling, task.wait, task.spawn, task.delay, and full wait() support.

  • RenderStepped / Heartbeat hooks
  • Default tick rate 60 Hz (adjustable 10–500)
  • Auto-execute folder

Attach Methods

Two handle modes: Standard (driver-style) and Force (own handle, tries multiple access masks).

  • Watchdog auto-detach if Roblox closes
  • Offset refetch from remote
  • VisualEngine + DataModel resolution

Drawing API

Hardware-accelerated overlay using layered windows. Supports Line, Square, Circle, Triangle, Text, and Image.

  • Transparency, ZIndex, Filled, Outline
  • Rounded corners and image rounding
  • Click-through toggle via setrobloxinput

Instance API

Walk the DataModel, read properties, call methods, and interact with Humanoids, Players, Camera, and more.

  • game, workspace, players
  • FindFirstChild, GetChildren, IsA
  • CFrame, Vector3, Color3, Enum support

Memory API

Direct read/write to the Roblox process. Read ints, floats, doubles, bytes, pointers, and strings.

  • memory_read / memory_write
  • getbase returns module base
  • VirtualProtectEx for read-only pages

Network & Files

HTTP GET/POST, request, WebSocket stub, and a sandboxed file system inside Workspace.

  • readfile, writefile, appendfile
  • listfiles, makefolder, delfile
  • Extension whitelist for safety

Drawing API

The Drawing library creates a transparent overlay on top of Roblox. It runs on its own render thread at ~240 FPS.

Shapes

All standard Drawing objects are supported with full property access.

  • Drawing.new("Line")
  • Drawing.new("Square")
  • Drawing.new("Circle")
  • Drawing.new("Triangle")
  • Drawing.new("Text")
  • Drawing.new("Image")

Images

Load images from raw bytes, Base64, or repaired PNG data. WIC fallback for exotic formats.

  • PNG, JPEG, GIF, BMP, WebP, TIFF, ICO
  • Rounded corners via Rounding
  • Transparency and ZIndex

Input Capture

Toggle whether the overlay swallows clicks or passes them through to Roblox.

setrobloxinput(true)  -- clicks pass through
setrobloxinput(false) -- overlay captures clicks

Instance Manipulation

CapyWare exposes a rich subset of the Roblox Instance API. You can traverse the DataModel, read properties, and call methods.

Supported Classes

Instance BasePart Model Humanoid Player Players Camera DataModel Workspace Lighting HttpService UserInputService RunService

Example

local players = game:GetService("Players")
local lp = players.LocalPlayer
local char = lp.Character
local hrp = char:FindFirstChild("HumanoidRootPart")

if hrp then
    print(hrp.Position)
    hrp.CFrame = CFrame.new(0, 50, 0)
end

Memory & FFlags

Low-level access to the Roblox process, plus fast flag manipulation.

Memory Read 

local base = getbase()
local value = memory_read("int", base + 0x1234)
print(value)

Supported types: int, float, double, byte, uintptr_t, string.

Memory Write 

local base = getbase()
local value = memory_write("int", base + 0x1234)
print(value)

Automatically uses VirtualProtectEx when the page is read-only.

FFlags 

setfflag("DFIntTaskSchedulerTargetFps", 240)
local target_fps = getfflag("DFIntTaskSchedulerTargetFps")

Read and write fast flags by name. RVA-based, verified against the flag table.

FPS Cap 

setfpscap(144)
print(getfpscap())

Writes the TaskScheduler MaxFPS field. Handles both seconds-per-frame and direct FPS formats.

Missing Features

CapyWare does not implement some commonly used Roblox APIs. This is not a matter of "not yet done" — the external approach CapyWare is built on simply cannot make these work. They require being inside the process with a real Roblox environment, which an external executor does not have.

Not Implemented

  • FireServer — remote event firing is not supported. Requires access to live RemoteEvent internals, which external memory access cannot reach.
  • Instance.new — cannot create new instances. Requires invoking Roblox's internal Instance constructor, which is not exposed to outside processes.
  • Destroy() — instance destruction is not available. Requires calling engine-side destruction logic, which is not reachable from an external handle.
